# Радио РБК — прямой эфир (MVP, офлайн)

Статический веб-плеер. Без сервера, без прокси.

## Запуск локально

Открыть `index.html` двойным кликом в Chrome.

## Как работает

- hls.js (Chrome/Firefox/Edge) или нативный HLS (Safari).
- Поток: https://hls-01-rbc.hostingradio.ru/rbc-fed0/112/playlist.m3u8
- AAC-LC 112 kbps.
- CDN РБК отдаёт CORS — прокси не требуется.

## Резерв

`server-backup/` — прокси ffmpeg (AAC→MP3), на случай блокировки CORS
или будущих задач (музыка, детектор повторов). В MVP не используется.

## Ограничения

- Трансляция без договора с РБК — только для демо.
- Upstream может смениться — обновить STREAM_URL.
