# Резервный прокси-сервер

Основной MVP работает без прокси — статика напрямую тянет HLS с CDN РБК.

Понадобится, если:
- CDN РБК закроет CORS;
- понадобится музыка в паузах;
- понадобится детектор повторов;
- Safari/iOS перестанут играть HLS нативно.

Запуск: docker build -t rbc-backup . && docker run -p 3000:3000 rbc-backup

## Состав

- `index.html` — прокси-версия плеера (`audio.src = PROXY + '/stream'`). Используется по умолчанию: сервер отдаёт её на `GET /`.
- `server.js` — прокси-сервер (ffmpeg AAC→MP3, `Content-Type: audio/mpeg`, CORS, общий ffmpeg на битрейт).
- `Dockerfile`, `.dockerignore`, `package.json`, `package-lock.json` — сборка и запуск контейнера.
- Статическая hls.js-версия плеера лежит в корне проекта (`../index.html`); в эту папку её не копировали — она зависит от CORS и резерву не нужна.

При активации резерва: заменить корневой `index.html` на этот, развернуть контейнер.
